# Mate wheels

Drive wheels for the 28BYJ-48 shaft. Generated by [`wheel.py`](wheel.py); change the constants at the top and re-run.

| File | What |
|---|---|
| `wheel-70.stl` | Drive wheel, 70 mm diameter, 8 mm wide. Print two. |
| `fit-test.stl` | Three shaft holes at +0.4 / +0.5 / +0.6 mm (1, 2, 3 notches). Print first if unsure. |

```bash
pip install manifold3d numpy
python wheel.py
```

## Size

- **70 mm diameter (35 mm radius).** At 800 half-steps/s that's about 4.3 cm/s; one half-step is about 0.054 mm of travel.
- Bigger is faster but pushes less and is less precise per step; smaller is slow. 70 mm (up from 60) is still fine for a small, light robot.

## Fit

- Shaft hole is double-D: **5.5 mm round, 3.5 mm across the flats** (shaft is 5.0 / 3.0, plus 0.5 clearance; the fit test picked 0.5 on this printer).
- The wheel should press on firmly by hand. If it's loose, set `CLEARANCE = 0.4`; if it won't go on, `0.6` (or use the fit test to pick).
- The 0.5 mm chamfer on the motor side helps the shaft start and hides elephant's foot.

## Printing

- Print **flat, motor side down** (the side with the web). No supports.
- PLA or PETG, 0.2 mm layers, 3 walls, 20–30% infill.

## Tire

- Centre groove: 2.5 mm wide, 1.2 mm deep (groove bottom 67.6 mm diameter).
- Use an O-ring (about 62–65 mm inner diameter, 2.5 mm cord) or two or three rubber bands. Bare plastic slips on the table.

## Mounting

- The wheel stops where the shaft's flats start, about 2 mm above the motor face, so it clears the motor's mounting ears.
- Mate also needs a third contact point: a ball caster or a smooth printed skid at the front or back.
